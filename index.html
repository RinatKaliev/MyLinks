MVP-концепция

  • Профили: mylinks.to/username + блоки ссылок, файлов, соцсетей
  • Файлы через Cloudflare R2 + signed URLs для приватных материалов
  • Без cookies: клики, гео, устройства, referrer + realtime счётчик
  • Готовность к монетизации: Stripe, тарифы Free / Pro / Team
